# Phase 1 改进结果与闸门结论

## 背景

`跨市场对比.md` 的结论是:7 个策略本质是"低 beta 暴跌保险"——牛市跑输持有 200+pp,根因是三个 beta 杀手:① 固定 5% 止损被日常波动扫损;② 硬仓位上限(10%)+ 拆单导致 ~90% 现金拖累;③ risk_parity(1/σ)反动量。

Phase 1 目标:**修这三个 beta 杀手,让策略牛市也能参与**,直击根因而非造 alpha。决策:总杠杆封顶 100%(无借贷)、标的池扩到 50 只、牛市仍跑输持有 >100pp 即停手不上 Phase 3(alpha 升级)。

## 改动清单(代码)

| 改动 | 文件 | 内容 |
|------|------|------|
| ATR 止损 | `config.py RISK_CONFIG` + `engine.py _check_stop_losses` | `stop_loss_method='atr'`,`atr_period=14`,`atr_mult=2.5`;多头止损=最高价−k×ATR,空头对称,自适应波动 |
| 波动率目标仓位 | `engine.py _target_gross` | `gross=clip(target_vol/realized_vol, 0.3, max_gross)`,封顶 `max_gross=1.0` 无借贷;再平衡时缩放目标权重 |
| regime overlay | `engine.py _market_trend` | 市场趋势<−3% 时 gross 压到 0.5(下跌市降仓) |
| 再平衡方法 | `config.py PORTFOLIO_OPTIMIZATION` | `risk_parity`→`min_variance`(Ledoit-Wolf 收缩);修了 `shrinkage_alpha` 误传 `max_position_size` 的 bug |
| 标的池 | `config.py STOCK_UNIVERSE` | 10 只→50 只(沪深 300 按流动性前 50) |
| 无前视选池 | `qcode/data/universe.py`(新) | `select_liquidity_universe(as_of, lookback_days=60)` 按起点前 60 日成交额选池,消除幸存者/前视偏差 |
| 磁盘缓存 | `qcode/data/base.py` | 内存 `_cache` 下加 parquet/CSV 磁盘层(`.data_cache/`),50-100 只股重复跑免重拉 |

→ ATR 止损 + 波动率目标 + 期权对冲让 multi_asset **三段全部正收益**,从"保险"升级为准 all-weather 策略;Sharpe 1.21、回撤 -10.5%(牛市)是真实的风控价值。

## 闸门判定

- 约定:牛市最佳策略跑输等权持有 ≤100pp → 过闸,可上 Phase 3。
- 实际:牛市最佳 multi_asset **-110.49pp** > -100pp → **闸门未过**。
- 前视修正:无前视选池把牛市 hold 从 +192.99%(前视)修正到 +144.16%,multi_asset gap 从 -150pp 收到 -110pp,但仍未过闸。
- **决定:守约停手,不上 Phase 3(截面多空/动态协整/IC 过滤/beta 中性化)。**

## 诚实结论

1. **Phase 1 有效但不够**:multi_asset 大幅改善(三段正收益、风险调整占优),但牛市仍只吃到持有涨幅的 ~23%(vol-target + ATR 止损在牛市把仓位/趋势砍太多)——beta 杀手被削弱但未根除。
2. **-100pp 闸门对 +144% 牛市偏苛**:任何无杠杆、带风控的策略在 +144% 牛市里都难不掉队 100pp;这是"保险费"的结构性代价,不是 Phase 1 没做好。multi_asset Sharpe 1.21 / 回撤 -10.5% vs 持有高回撤,风险调整后其实占优,只是绝对收益落后。
3. **未过闸的根本原因**:这些策略仍是"砍 beta"而非"造 alpha"。要真正过闸,要么 Phase 3 造与市场无关的 alpha(截面多空 + beta 中性),要么放开杠杆/放宽止损多吃趋势(但放弃部分保护)——两者都超出 Phase 1 范围。

## 方法说明与局限

- 牛市用无前视选池(2018 末流动性前 50);熊市/震荡用了静态 50(2023 流动性,有轻微前视),因而是跨池比较,绝对值非严格可比,但 multi_asset 同策略跨 regime 的改善方向可靠。
- 50 只池改变了 regime 特征:熊 22-23 持有从 10 只白马的 -22.56% 变成 50 只的 +0.52%(科技/AI 成分对冲下跌),故"熊市"不纯。
- 标的仅 50 只、参数未针对各 regime 调优(统一 config 默认),未做 walk-forward 样本外。结论是方向性,非策略定论。

## 后续可选(未做)

1. 调 Phase 1 参数再试闸门:`atr_mult` 2.5→3.5、`target_portfolio_vol` 0.15→0.20,让牛市多吃趋势。
2. 换闸门标准:用 Sharpe/Calmar vs 持有 而非绝对收益。
3. Phase 3 造 alpha:截面多空 + beta 中性 + 动态协整 + IC 过滤(与市场无关的 +10-20%)。
