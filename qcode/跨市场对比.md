## 3. 关键结论（新）

1. **牛市:8 策略全部跑输持有 -158~-234pp**——结构性低 beta,换因子救不了(原 200+pp 结论在新数据下依旧成立,只是口径更诚实)。
2. **弱熊(高波动横盘):仅 multi_asset 跑赢(+15.8pp),且回撤 -13.6% vs 市场 -46%**——"少动+风控"在弱市兑现价值。
3. **回撤是策略唯一稳定的优势**:三区间里策略回撤普遍远小于持有(如 cross_sectional 弱熊 -7.3% vs 市场 -46%)。**这些策略是"用牛市涨幅换回撤削减"的保险。**
4. **cross_sectional 是全环境最稳**:牛市不落后太多(-159pp 最低档)、震荡回撤最小(-3.5%)、弱熊与市场持平。2024-2025 样本外 +72.95%/Sharpe 1.99 进一步验证(见改进点.md)。
5. **均值回归类(mean_reversion/stat_arb)三区间全负**——2021 分化震荡 + 2022 阴跌对它双重不利;旧版"震荡市均值回归占优"结论在新池下不成立。
6. **样本外验证否决了"仅 pb"**:该配置 2022-23 弱熊 +38.1%(+37.6pp)亮眼,但 2024-25 只 +19.98%,而当前组合 +72.95%——详见改进点.md 启示 #2。

## 4. 方法论说明（新）

- 50 只池按 2023 流动性选入(有轻微前视),分段收益由单次 2019-2023 回测净值曲线切分,带 365 天预热(2018 数据热身指标),含 T+1/涨跌停/印花税/过户费/杠杆封顶。
- 结论是方向性的:样本 5 年、池 50 只、参数未针对各 regime 调优;2024-2025 作为独立样本外复核了 cross_sectional(见改进点.md)。

## 3. 关键结论

### 3.1 保险的"赔付"与"保费"
- **熊市 + 震荡市(持有下跌或近持平)**:7 策略**全部跑赢持有** +0.65 ~ +25.08pp → 保险兑现。
- **牛市(持有大涨)**:7 策略**全部惨败** -213 ~ -234pp → 保费灾难性。
- **全周期净额**:每个策略都亏持有约 **-192 ~ -204pp**。熊+震荡两段攒下的 +20~+35pp 赔付,牛市一段就吐回 200+pp。除非判断未来"只阴跌、无牛市",否则长期持有完胜。

### 3.2 策略本质是低 beta / 市场中性
策略自身收益跨三段几乎不动,而持有在天壤之别:

| | 收益区间 (max-min) | 跨 regime 表现 |
|------|-------------------|----------------|
| momentum | **1.3pp** (2.5~3.8) | 几乎完全市场中性,涨跌都不沾 |
| mean_reversion | 6.9pp | 极低 beta |
| multi_asset | 7.0pp | 极低 beta |
| multi_factor | 17.7pp | 低 beta |
| stat_arb | 20.8pp | 低 beta |
| regime | 21.0pp | 低 beta |
| pairs_trading | 30.2pp | 策略里 beta 最高 |
| **买入持有** | **259.3pp** (-22.6 ~ +236.8) | 全额吃市场 |

→ 这些策略的"风控"(止损/做空/择时)本质上把市场 beta 砍掉了:既不吃暴跌也不参与牛市。所谓"熊市跑赢"只是低 beta 的副产品,不是 alpha。

### 3.3 beta 越高、全周期越少亏
pairs_trading 是 7 个里 beta 最高的(牛市能拿 +23.45%,区间 30pp),全周期净额 -192.27pp 也是最少亏的;momentum 最中性(区间 1.3pp),牛市几乎不参与(+2.91%),全周期净 -198.57pp。在"防御型"策略族里,**稍微多带点 beta 的反而少亏**——但都远不够,仍输持有 190pp+。

### 3.4 选策略 = 选"保费/赔付"档位,而非选 alpha
三段共同表明:这些策略不是"跑赢市场的 alpha",而是**不同保费/赔付档位的暴跌保险**。其价值的唯一来源是"大跌时段保护资本",代价是"放弃整轮牛市"。是否选用,取决于对**未来大跌频率**的判断与对**平时跑输**的容忍度——而非历史回测的胜率/超额均值(那些会被单只暴跌股严重扭曲,见 [熊市策略回测结果.md](熊市策略回测结果.md) §6)。

## 4. 方法说明与局限

- 数据源 baostock(前复权,真实行情);不同后端(akshare/tushare)复权口径略异,绝对值可能小幅出入,结论不变。
- 三段非连续(2019-20 → 2021 → 2022-23),全周期净额为各段超额简单相加,非严格连续复利,仅作量级参考。
- 标的仅 10 只白马股,结论不可外推到全市场;策略参数未针对各 regime 调优(统一用 config.py 默认),实盘需 walk-forward/样本外验证。
- 牛市段持有 +236.75% 极端强劲,放大了"保费"幅度;若用更温和的牛市,策略落后幅度会收窄,但方向不变。
