# QCode 改进点 —— 从回测框架走向机构水平

> 目标：把当前"个人回测框架"逐步升级为"接近机构水平的研究平台"。
> 本文档按 ROI（投入产出比）排序给出改进路线，每层都标注**机构做法**与**本项目落地**（含文件级落点）。
> 打勾项 = 已完成。跟随文档逐步推进即可。

---

## 〇、全局观：机构流水线长什么样

机构不是一个"更好的回测"，而是一条**每级都有纪律的流水线**：

```
数据治理 → 因子研究(IC检验/样本外) → 组合构建 → 分层风控 → 执行模型 → 运营复盘
   ↑              ↑                    ↑          ↑          ↑          ↑
  当前: 日线     当前: 无检验         当前: 简单    当前: 日频  当前: 收盘价 当前: 无
  baostock      手工阈值             min_var     事后减仓    固定成本    手动跑
```

下面 6 层就是这条流水线的每一段。逐层补齐 = 接近机构水平。

### 机构做法

- 历史指数成分（消除幸存者偏差）
- 财务/日历数据（除权除息、停牌、涨跌停标记）

### 本项目落地

## 二、因子研究纪律（机构的第一关，本项目最大短板）

### 机构做法
任何因子**先过 IC 检验，再过样本外，才进组合**。没有检验的因子 = 噪音。

### 本项目落地
- [x] **IC 检验接入**（Phase A，已完成 2026-08-14）：
  - `qcode/utils/significance.py` 新增 `factor_ic_report()`（多周期 mean_IC/ICIR/FDR）+ `suggest_weights()`（按 ICIR 建议权重）
  - 新 CLI `factor_report.py`：`python factor_report.py`（离线样本）/ `--real`（真实数据）
  - 报告判词逻辑：IC≈0 → "回测收益大概率来自 beta 与参数拟合，不是因子 alpha"
- [x] **7 策略信号 IC 横向对比**（已完成 2026-08-14）：
  - 新 CLI `signal_report.py`：`python signal_report.py`（默认 7 策略对比）/ `--strategy momentum`（单策略）
  - 因子检验方法论通用化——每个策略提取"打分列"（momentum/regime 信号方向、mean_reversion 布林带距离、stat_arb z-score、multi_asset 持仓信号、multi_factor alpha_score），统一跑 IC/ICIR/FDR；离散信号额外算"入场日 IC"（只在信号变化日）
  - pairs_trading 因是配对级信号，单独一节报告"价差 z-score 预测回归"的配对级 IC
- [x] **真实数据复核**（已完成 2026-08-14，baostock，6 只，2022-2023）：
  - `signal_report.py --real`：**momentum 真实数据 IC@5=+0.048/ICIR=0.34（正！与样本数据结论相反）**；multi_asset IC@10=+0.118；stat_arb 慢周期有效（IC@20=+0.121）；multi_factor 综合信号强负（IC@20=-0.238）；regime 负
  - `factor_report.py --real`：**value_score 是唯一强有效因子（IC@20=+0.162、ICIR=1.02）**——"价格低于 60 日均线"的长期反转逻辑在真实数据成立；**volatility_score 强反向（IC@20=-0.294、ICIR=-1.36）**；momentum_score/volume_score 无效
  - **实锤结论：multi_factor 权重配比错误**——最有效的 value 因子权重只有 0.3，强反向的 volatility 因子却有 0.2，把正的拖成负的（alpha_score IC@20=-0.216）
  - **教训：样本数据结论不可信**（momentum 样本负/真实正；配对样本招行平安最强/真实美的伊利最强）——以后一律以 `--real` 为准
- [x] **按真实数据改造 multi_factor**（已完成 2026-08-14）：
  - `config.MULTI_FACTOR_ALPHA` 重配：momentum 0.4→**0**（IC≈0）、value 0.3→**0.6**（ICIR=1.02 唯一强正）、volatility 0.2→**-0.4**（强反向 ICIR=-1.36，权重取负=反转使用）、volume 0.1→**0**（IC≈0）
  - 复测效果（真实数据 6 只）：alpha_score IC@5 **-0.055→+0.112**、IC@20 **-0.216→+0.328**、ICIR@5 **-0.66→+1.93**——合成信号从"负预测力"翻转为"强正预测力"，且强于单独 value（反向 volatility 有叠加价值）
  - `factor_report.py` 同步修复：改用 config 权重（原用策略默认权重，导致报告与实跑不一致）；`signal_report.py` 同理
  - 回归基线已更新（multi_factor 行为有意变更，`tests/test_regression.py --update`）；样本收益 1,138,130→1,207,930
- [ ] **修掉假价值因子**：`qcode/strategies/alpha_mining.py` 的 `value_score = (sma60-close)/sma60` 目前是"价格低于 60 日均线"的**反转代理**（真实数据证明其 IC 有效，但这不是基本面价值）→ 若要真价值因子，用 tushare 财务数据（PB/PE/ROE 排名），并重新做 IC 检验对比
- [ ] **修掉假价值因子**：`qcode/strategies/alpha_mining.py` 的 `value_score = (sma60-close)/sma60` 是反转因子不是基本面价值 → 换成 tushare 财务数据（PB/PE/ROE 排名）
- [ ] **参数高原纪律**：不找参数峰值，找"参数附近 30% 范围内都稳定"的区域；每个参数组合跑 walk-forward，报告 OOS 稳定性而非单段收益
- [ ] **实验记录**：每次调参记录 git commit + 参数 + OOS 结果，防止"回测过拟合"自我欺骗

## 三、组合构建升级

### 机构做法
全协方差 + 约束优化（行业中性、风格中性、换手约束），目标函数明确（max Sharpe / 风险预算 / 跟踪误差）。

### 本项目落地
- [ ] **行业中性**：`qcode/risk/manager.py` 的 min_variance 优化加约束——按申万一级行业分组，组内权重之和受限
- [ ] **换手约束**：单月换手 ≤ 阈值，减少交易成本
- [ ] **风格暴露报告**：每次回测输出组合相对基准的 beta/市值/行业偏离度表（机构风控报告的第一项）

---

## 四、分层风控 + 压力测试

### 机构做法
策略层 → 组合层 → 公司层三级风控；压力测试/情景回放；流动性限额；开仓前检查而非事后减仓。

### 本项目落地
- [ ] **压力测试**（新 `qcode/risk/stress.py`）：把 2015 股灾、2018 单边跌、2022 阴跌三段的真实行情作为情景，强制注入回测引擎重放，看组合最大回撤是否可承受
- [ ] **流动性约束**：持仓市值 ≤ 该股日均成交额 × 阈值（如 1%），防止"账面收益卖不出去"——50 只池里小盘股几乎必然触发
- [ ] **风控前移**：从日频事后减仓（`engine._reduce_positions`）升级为**开仓前检查**——行业敞口、单日亏损限额、流动性，任一超标不开仓

## 五、执行模型（把"账面收益"变成"可实现收益"）

### 机构做法
冲击成本模型（平方根法则：冲击 ∝ √(订单量/ADV)）、TWAP/VWAP 分时模拟、融券池约束。

### 本项目落地
- [ ] **动态滑点**：`engine._apply_costs` 升级为成交量相关——滑点 = 固定部分 + k×√(成交额/日均成交额)，大单自动吃更多成本（当前最虚的一环，样本数据 +70% 实盘要打 2-3 折）
- [ ] **可成交性检查**：信号开仓前校验"该股当日成交额能否消化这个仓位"，不能则降仓/跳过（挂在 `engine._execute_signal`）
- [ ] **融券池约束**：A 股不是所有票都能融券，加"可融券名单"过滤 OPEN_SHORT

## 八、现实边界（说句实话）

一个人能做到的上限是"**精品研究型**"，不是"系统型"：

- **能做到**：上面 A-E 全部——这是一个可信的单人量化研究平台，结论能支撑"某策略值得继续投入"的决策
- **做不到（也不需要）**：实时行情、多市场直连、子账户隔离、合规审计、几十亿容量——那些是团队和牌照的事
- **性价比最高的单点**：Phase A（已完成）。`significance.py` 写了 106 行却一行没被调用，等于研究没有"体检"环节——接上它、删掉无效因子，比任何新策略都值钱
